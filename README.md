# RGS TOWER — متجر ملابس رجالي (Django)

متجر إلكتروني كامل بتطبيق واحد اسمه `dashboard`، وفولدر `templates` واحد متقسّم لفولدرات.

---

## التشغيل

من داخل فولدر المشروع (اللي فيه `manage.py`):

```bash
pip install -r requirements.txt

python manage.py migrate             # بيطبّق 0002 و 0003 (الحسابات، الدفع، أعمالنا، التقييمات...)

python manage.py seed_store          # أول مرة بس: محافظات + مقاسات + أقسام + أقسام الرئيسية + القائمة + السياسات
python manage.py createsuperuser     # أول مرة بس: حساب المدير الأساسي

python manage.py runserver
```

- المتجر: <http://127.0.0.1:8000/> (عربي) · <http://127.0.0.1:8000/?lang=en> (إنجليزي)
- لوحة التحكم: <http://127.0.0.1:8000/dashboard/>
- Django admin (احتياطي): <http://127.0.0.1:8000/django-admin/>

> الميجريشنز `0002` و `0003` متضافة للريبو — مش محتاج `makemigrations`، `migrate` بس.

## المزايا

**المتجر**
- عربي (أساسي) + إنجليزي بزرار في الناف بار، RTL و LTR
- دارك مود بس — اللون الأساسي `#B04B00` والثانوي `#D8CBC1`
- حسابات للعملاء: تسجيل، دخول بالإيميل أو الموبايل، «حسابي» (طلباتي، بياناتي، كلمة المرور)
- لازم العميل يسجل دخول قبل ما يطلب؛ بياناته بتتسجل في «العملاء» في لوحة التحكم
- الدفع: PayPal (لينك دفع و/أو زرار PayPal الرسمي) + الدفع عند الاستلام
- «أعمالنا»: معرض صور وفيديوهات (رفع فيديو أو لينك يوتيوب/فيميو)، فلاتر بالتصنيف، عارض بملء الشاشة،
  ولما تبعت رابط عمل بيظهر البانر بتاعه تحت الرابط (Open Graph)
- «تقييمات العملاء»: متوسط + توزيع النجوم؛ العميل اللي دفع بس هو اللي يقدر يقيّم
- السياسات (خصوصية، استبدال، شحن، شروط…) بتتكتب من لوحة التحكم وتظهر في الفوتر
- الصفحة الرئيسية بأقسام بتترتب وتتخفي وتتعدل من لوحة التحكم

**لوحة التحكم**
- العملاء: بحث، ترتيب، ملف لكل عميل (طلباته، مدفوعاته، تقييماته، ملاحظات)، تصدير CSV، إيقاف حساب
- الطلبات: حالة الدفع + تأكيد الدفع يدوي لمدفوعات اللينك؛ الإلغاء بيرجّع المخزون
- أعمالنا: نشر/تعديل/حذف، رفع صور وفيديوهات، ترتيب وتعليقات، أي صورة تبقى البانر، تصنيفات
- التقييمات: موافقة/إخفاء، تمييز في الرئيسية، رد المتجر، تعديل، حذف
- الصفحة الرئيسية: ترتيب الأقسام وإظهارها وتعديل عناوينها وصورها
- القائمة (الناف بار): روابط جاهزة، أقسام، سياسات، أو روابط مخصصة — ترتيب وإخفاء
- الإدارة: إضافة إداريين بصلاحيات محددة لكل قسم
- الدفع: لينك PayPal، سعر الدولار، Client ID/Secret، تشغيل/إيقاف الدفع عند الاستلام

## PayPal

- PayPal مش بيقبل الجنيه المصري، فالمبلغ بيتحوّل لدولار بسعر الصرف اللي في «الدفع».
- **لينك الدفع** (PayPal.me): العميل بيدفع ويضغط «أنا دفعت»، والطلب يستنى تأكيدك من لوحة التحكم.
- **زرار PayPal الرسمي** (لو حطيت Client ID + Secret): الدفع بيتأكد أوتوماتيك والطلب يتعلّم «مدفوع».
  جرّب الأول بـ Sandbox وبعدين اقفله.

## ملاحظات

- تحت الرابط (البانر) بيظهر لما الموقع يكون مرفوع على دومين حقيقي — واتساب وفيسبوك مش بيشوفوا `127.0.0.1`.
- قبل الرفع على سيرفر حقيقي: غيّر `SECRET_KEY`، خلّي `DEBUG = False`، حدّد `ALLOWED_HOSTS`
  و`CSRF_TRUSTED_ORIGINS`، وشغّل الموقع على HTTPS (مطلوب لـ PayPal).
