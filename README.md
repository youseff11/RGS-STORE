# RGS TOWER — خدمات جرافيك (Django)

متجر إلكتروني كامل بتطبيق واحد اسمه `dashboard`، وفولدر `templates` واحد متقسّم لفولدرات.

---

## التشغيل

من داخل فولدر المشروع (اللي فيه `manage.py`):

```bash
pip install -r requirements.txt

python manage.py migrate             # بيطبّق 0002 → 0008 (الحسابات، الدفع، أعمالنا، التقييمات، الدول، التذاكر والإيميل، الدخول بجوجل)

python manage.py seed_store          # أول مرة بس: دول الشحن + أقسام + أقسام الرئيسية + القائمة + السياسات
python manage.py createsuperuser     # أول مرة بس: حساب المدير الأساسي

python manage.py runserver
```

- المتجر: <http://127.0.0.1:8000/> (عربي) · <http://127.0.0.1:8000/?lang=en> (إنجليزي)
- لوحة التحكم: <http://127.0.0.1:8000/dashboard/>
- Django admin (احتياطي): <http://127.0.0.1:8000/django-admin/>

> كل الميجريشنز متضافة للريبو — مش محتاج `makemigrations`، `migrate` بس.

## المزايا

**المتجر**
- عربي (أساسي) + إنجليزي بزرار في الناف بار، RTL و LTR
- دارك مود بس — اللون الأساسي `#B04B00` والثانوي `#D8CBC1`
- حسابات للعملاء: تسجيل، دخول بالإيميل أو الموبايل، **أو الدخول بحساب جوجل بضغطة واحدة**،
  «حسابي» (طلباتي، بياناتي، كلمة المرور)
- لازم العميل يسجل دخول قبل ما يطلب؛ بياناته بتتسجل في «العملاء» في لوحة التحكم
- الدفع: PayPal (لينك دفع و/أو زرار PayPal الرسمي) + الدفع عند الاستلام
- «أعمالنا»: معرض صور وفيديوهات (رفع فيديو أو لينك يوتيوب/فيميو)، فلاتر بالتصنيف، عارض بملء الشاشة،
  ولما تبعت رابط عمل بيظهر البانر بتاعه تحت الرابط (Open Graph)
- «تقييمات العملاء»: متوسط + توزيع النجوم؛ العميل اللي دفع بس هو اللي يقدر يقيّم
- السياسات (خصوصية، استبدال، شحن، شروط…) بتتكتب من لوحة التحكم وتظهر في الفوتر
- الصفحة الرئيسية بأقسام بتترتب وتتخفي وتتعدل من لوحة التحكم
- الشحن بالدول: كل دولة ليها سعر شحن وحد شحن مجاني ومدة توصيل، والعميل بيختار دولته وهو بيطلب
- **تذاكر الدعم**: العميل المسجّل بيفتح تذكرة من «الدعم والتذاكر» ويرفع صور وملفات ويسجّل رسالة صوتية،
  ويتابع الرد في نفس الصفحة

**لوحة التحكم**
- العملاء: بحث، ترتيب، ملف لكل عميل (طلباته، مدفوعاته، تقييماته، ملاحظات)، تصدير CSV، إيقاف حساب
- الطلبات: حالة الدفع + تأكيد الدفع يدوي لمدفوعات اللينك
- **الخدمات** (بدل المقاسات): بتكتبها بنفسك من «الخدمات» — اسم عربي/إنجليزي + سعر إضافي بيتزوّد على سعر الديزاين
  + تشغيل/إيقاف. لكل ديزاين بتختار الخدمات المتاحة من صفحة «٣. الخدمات». الخدمات ملهاش مخزون (متاحة دايمًا)،
  والعميل بيختار اللون + الخدمة والسعر بيتحدّث قدامه
- أعمالنا: نشر/تعديل/حذف، رفع صور وفيديوهات، ترتيب وتعليقات، أي صورة تبقى البانر، تصنيفات
- التقييمات: موافقة/إخفاء، تمييز في الرئيسية، رد المتجر، تعديل، حذف
- الصفحة الرئيسية: ترتيب الأقسام وإظهارها وتعديل عناوينها وصورها
- القائمة (الناف بار): روابط جاهزة، أقسام، سياسات، أو روابط مخصصة — ترتيب وإخفاء
- الإدارة: إضافة إداريين بصلاحيات محددة لكل قسم
- الدفع: لينك PayPal، سعر الدولار، Client ID/Secret، تشغيل/إيقاف الدفع عند الاستلام
- الدول والشحن: كل دول العالم جاهزة، بحث وتفعيل جماعي وسعر شحن لكل دولة
- تذاكر الدعم: كل التذاكر بحالاتها، الرد بمرفقات، قفل/فتح التذكرة
- الإشعارات والإيميل: جيميلك + سويتش لكل نوع إشعار + زرار تجربة إرسال
- الدخول بجوجل: تشغيل/إيقاف + Client ID و Secret + اللينكات اللي جوجل محتاجاها جاهزة للنسخ

## PayPal

- PayPal مش بيقبل الجنيه المصري، فالمبلغ بيتحوّل لدولار بسعر الصرف اللي في «الدفع».
- **لينك الدفع** (PayPal.me): العميل بيدفع ويضغط «أنا دفعت»، والطلب يستنى تأكيدك من لوحة التحكم.
- **زرار PayPal الرسمي** (لو حطيت Client ID + Secret): الدفع بيتأكد أوتوماتيك والطلب يتعلّم «مدفوع».
  جرّب الأول بـ Sandbox وبعدين اقفله.

## الإشعارات على الإيميل

من «الإشعارات والإيميل» في لوحة التحكم:

1. شغّل «تشغيل الإيميلات» واكتب الجيميل اللي هتستقبل عليه.
2. في «حساب الإرسال (SMTP)» حط الجيميل و**App password** من جوجل (الأمان ← التحقق بخطوتين ← App passwords)
   — باسورد الإيميل العادي مش هينفع. الهوست `smtp.gmail.com` والبورت `587` مع TLS.
3. اختار الإشعارات اللي عايزها: طلب جديد · تذكرة أو رد جديد · رسالة «اتصل بنا» · تقييم جديد،
   وكمان تأكيد الطلب ورد التذكرة اللي بيروحوا للعميل.
4. «جرّب الإرسال» بيبعت إيميل تجربة ويقول لك الخطأ لو فيه مشكلة.

الإيميلات بتتبعت في الخلفية (thread) وبتتصمم بهوية المتجر، ولو السيرفر مش قادر يبعت الطلب بيكمل عادي.
استضافة PythonAnywhere المجانية بتمنع إرسال الإيميل — محتاج خطة مدفوعة.

## الدخول بحساب جوجل

من «الدخول بجوجل» في لوحة التحكم:

1. افتح `console.cloud.google.com` بحسابك واعمل مشروع جديد.
2. `APIs & Services ← OAuth consent screen` ← اختار **External** واكتب اسم المتجر وإيميلك،
   وفي `Data access` ضيف `openid · email · profile` وبس.
3. `Credentials ← Create credentials ← OAuth client ID` ← النوع **Web application**.
4. الصق الـ **origin** والـ **redirect URI** اللي الصفحة بتعرضهم لك (مثال محلي:
   `http://127.0.0.1:8000` و`http://127.0.0.1:8000/account/google/callback/`) واضغط Create.
5. انسخ الـ Client ID والـ Client secret وحطهم في الصفحة، احفظ، وشغّل السويتش —
   الزرار بيظهر في `/account/login/` و`/account/register/`.
6. وانت في وضع Testing ضيف نفسك في **Test users**، ولما تخلص اضغط **Publish app**.

الملاحظات المهمة:

- الـ redirect URI لازم يبقى مطابق حرف بحرف، وإلا جوجل بترد بـ `redirect_uri_mismatch`.
  لما ترفع على الدومين ضيف نسخته كمان (جوجل بتقبل أكتر من لينك).
  الصفحة بتبني اللينك من لينك المتجر المحفوظ في «الإشعارات والإيميل» لو انت على نفس الدومين، وإلا من اللينك الحالي.
- الإيميل والاسم بيجوا من جوجل، والموبايل والعنوان بيتطلبوا من العميل وقت الطلب زي أي حساب.
- لو الإيميل ده كان عامل حساب بكلمة مرور قبل كده، الحسابين بيتربطوا (مفيش حساب مكرر) —
  الربط بيتم على `sub` بتاع جوجل علشان يفضل شغال حتى لو العميل غيّر الجيميل.
- حساب جوجل مالوش كلمة مرور عندنا؛ العميل يقدر يضيف واحدة من «حسابي ← كلمة المرور».
- الـ Client secret بيتحفظ في الداتابيز ومش بيتعرض تاني — سيب الخانة فاضية علشان يفضل زي ما هو.

## ملاحظات

- تحت الرابط (البانر) بيظهر لما الموقع يكون مرفوع على دومين حقيقي — واتساب وفيسبوك مش بيشوفوا `127.0.0.1`.
- قبل الرفع على سيرفر حقيقي: غيّر `SECRET_KEY`، خلّي `DEBUG = False`، حدّد `ALLOWED_HOSTS`
  و`CSRF_TRUSTED_ORIGINS`، وشغّل الموقع على HTTPS (مطلوب لـ PayPal).
