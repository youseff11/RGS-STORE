# RGS TOWER — متجر ملابس رجالي (Django)

متجر إلكتروني كامل بتطبيق واحد اسمه `dashboard`، وفولدر `templates` واحد متقسّم لفولدرات.

---

## التشغيل لأول مرة

من داخل فولدر المشروع (اللي فيه `manage.py`):

```bash
pip install -r requirements.txt

python manage.py makemigrations dashboard
python manage.py migrate

python manage.py seed_store          # محافظات + مقاسات + أقسام + إعدادات مبدئية
python manage.py createsuperuser     # حساب الأدمن بتاعك

python manage.py runserver
```

- المتجر: <http://127.0.0.1:8000/>
- لوحة التحكم: <http://127.0.0.1:8000/dashboard/>
- Django admin (احتياطي): <http://127.0.0.1:8000/django-admin/>

## هيكل المشروع

```
Core/                     إعدادات المشروع
dashboard/                التطبيق الوحيد
  models.py               كل الجداول
  views.py                صفحات المتجر (الواجهة)
  dashboard_views.py      صفحات لوحة التحكم
  forms.py                فورمات لوحة التحكم
  urls.py                 كل الروابط
  utils.py                السلة والحسابات
  i18n.py                 نصوص الواجهة عربي/إنجليزي
  middleware.py           تبديل اللغة
  context_processors.py   بيانات عامة لكل الصفحات
  templatetags/           فلاتر وتاجات القوالب
  management/commands/    seed_store
templates/
  base/                   base.html + dashboard_base.html
  partials/               الهيدر، الفوتر، الشريط المتحرك، كارت المنتج...
  pages/                  صفحات المتجر
  dashboard/              صفحات لوحة التحكم
static/css, static/js     التصميم والسكربتات
media/                    الصور المرفوعة
```

## المزايا

**المتجر**
- عربي / إنجليزي بزر تبديل، مع RTL و LTR
- لايت مود و دارك مود (الاختيار متحفوظ في المتصفح)
- أقسام، فلاتر (قسم، مقاس، السعر)، ترتيب، بحث، ترقيم صفحات
- صفحة منتج بألوان ومقاسات، وصور مختلفة لكل لون، والمخزون بيتحدّث لحظيًا
- سلة مشتريات، كود خصم، شحن مجاني فوق مبلغ معيّن
- إتمام طلب كامل بالدفع عند الاستلام (من غير بوابات دفع)
- صفحة تتبع الطلب برقم الطلب + الموبايل
- شريط إعلانات متحرك فوق الموقع
- أيقونات فيسبوك وإنستجرام (وتيك توك ويوتيوب وواتساب) في الفوتر

**لوحة التحكم**
- إحصائيات ومخطط مبيعات آخر ٧ أيام، وتنبيه المخزون القليل
- المنتجات على ٣ خطوات: البيانات → الألوان والصور → المقاسات والكميات
- جدول كميات (لون × مقاس) لكل منتج
- الطلبات: بحث، فلترة، تغيير الحالة، فاتورة للطباعة
- أكواد الخصم (نسبة أو مبلغ، حد أدنى، عدد استخدامات، مدة، شحن مجاني)
- العروض التلقائية: على كل المنتجات، أو قسم، أو منتجات محددة
- الشريط المتحرك، البانرات، الأقسام، المقاسات، المحافظات، رسائل العملاء
- إعدادات المتجر: اللوجو، لينكات السوشيال، الشحن، العملة

## ملاحظات

- سعر الشحن ثابت من الإعدادات، مع شحن مجاني فوق مبلغ معيّن، وممكن سعر خاص لأي محافظة.
- قبل الرفع على سيرفر حقيقي: غيّر `SECRET_KEY`، خلّي `DEBUG = False`، وحدّد `ALLOWED_HOSTS`.
